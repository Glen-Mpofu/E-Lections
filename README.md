## E-Lections
an online voting platform I developed for my Residence for the annual Res Committee Candidate Voting.

**Tech Stack:** 
* React Native
* JavaScript
* Node.js
* Express.js
* postgreSQL - Database

**Security Features**
* The site uses JWT tokens to verify the user that is logged in.
* The site has no login feature. Only the students residing in the residence were able to access the portal and cast their votes
* The site was only available on the local res WIFI and was managed and maintained by me on my laptop.

**Features**
* Vote casting - On the dashboard you'll find a list of candidates (14) and you can only vote for 7

## How to run 
```sh
git clone <this-repository-url>
```
**frontend**
```sh
cd frontend
npm start
```

**backend**
```sh
cd frontend
npm start
```
